# 2026-10-08 — hidden fit measurement

Michael chose to preserve exact fitting over estimating from the current zoom's bounds. Fit therefore measures content at each candidate detent while the visible canvas stays at its current view. Measurement reuses the node drawing path in an isolated input-disabled canvas within the same frame, avoiding retained draw buffers and font-texture lifetimes across frames. Node callbacks now have an explicit measurement pass; Patchbay's callbacks only declare labels and pins and need no adaptation.

Patchbay still pins dfx v0.1.12. Adoption awaits Michael's dfx commit/tag and a Patchbay dependency bump.
