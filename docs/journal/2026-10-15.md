# 2026-10-15 — NodeCanvas mini-map stage 1

Michael found 3,000 nodes acceptable but 5,000 choppy in the first hands-on pass. Profiling traced most CPU time to `NodeCanvas.textColor` copying ImGui's entire style-color array for every label and pin row. A direct color lookup cut the 5,000-node headless CPU frame from about 96 ms to 36 ms; the full manual matrix and post-fix responsiveness are unverified. Stage 2 still waits on that assessment. A generic ImGui list clipper is unsuitable for this freely positioned, variably sized graph; any remaining visibility optimization must preserve current-detent measured bounds, pins, fit, and widget routing.
