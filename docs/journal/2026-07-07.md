## Gotchas the documents encode (verified against pinned cimgui-go v1.5.0 source)

- `imgui.FontSize()` must never be passed to `PushFont` — use `imgui.CurrentStyle().FontSizeBase()`.
- The canvas-level drawlist split must use an owned `imgui.DrawListSplitter`, never `ChannelsSplit` (imgui tables split internally; the convenience path can't nest).
- `fmt.Sprint` of a struct pointer renders `&{fields}`, not an address — the ID scoping rule special-cases pointer kinds via `%p`.
- Material icon merge uses fixed pixel glyph offsets (`fonts.go:48,75`) — icon baselines at reduced detents are a watch item for stage 3.

## Stage 1 — pure core (implementation agent, later same day)

`nodeCanvasGeometry.go` and `nodeCanvasInput.go` landed with headless tests (`nodeCanvasGeometry_test.go`, `nodeCanvasInput_test.go`); `make test` green. Decisions made within the work order's discretion, recorded for later stages:

- The public intent types (`Intents`, `NodeMove`, `LinkCreate`, `SelectionChange`) and `View` live in the stage-1 files for now — the machine and geometry core need them to compile and test. The deliverables table assigns them to `nodeCanvas.go`; move them there in stage 2/3 if it reads better, or leave with a note.
- `inputSnapshot.leftDragging` is defined *sticky*: true once the drag threshold is exceeded at any point during the press, holding through the release frame. imgui's `IsMouseDragging` drops on the release frame, which would misread a fast flick (press → threshold+release in one frame) as a click. Stage 4's snapshot sampling must implement the sticky semantics (track max drag distance canvas-side or use `MouseDragMaxDistanceSqr`).
- Wheel detent stepping is honored only in the `idle` gesture state (one gesture at a time; no mid-gesture transform changes). The work order's initiation predicates don't name idleness for wheel; this is the conservative reading — revisit if zoom-during-pan wants support.
- `viewChanged` in `gestureResult` reports only *actual* view mutations (a wheel event already clamped at the max detent doesn't set it). Stage 5's pending-fit cancellation may want "navigation attempted" instead; decide there.
- Hit-test tie-breaks: within a node, nearest pin wins, exact ties to the later-declared pin; links nearest by bezier distance, exact ties to later-declared. Pin *snap* is globally nearest compatible in screen space (not z-ordered) per the work order.
